# Workshop-introduction-front
# 🚀 Workshop Front-End pour Débutants

Bienvenue dans ce dépôt GitHub !

Ce projet a été réalisé dans le cadre d'un **workshop d'initiation au développement Front-End**. L'objectif est de permettre à des débutants de découvrir les bases du développement web en créant leur première page web avec **HTML** et **CSS**.

---

# 📚 Objectifs du workshop

À la fin de cet atelier, les participants seront capables de :

* Comprendre la différence entre le **Front-End** et le **Back-End**.
* Comprendre le fonctionnement d'un site web.
* Créer une page web en **HTML**.
* Structurer correctement une page avec les balises HTML.
* Ajouter des images, des liens, des listes et des tableaux.
* Utiliser les balises sémantiques (`header`, `nav`, `main`, `section`, `footer`).
* Mettre en forme une page avec **CSS**.
* Modifier les couleurs, les polices, les marges et les espacements.
* Organiser un projet HTML/CSS simple.

---

# 📖 Contenu du workshop

## Chapitre 1 – Introduction

* Qu'est-ce que le Front-End ?
* Différence entre Front-End et Back-End
* Fonctionnement d'un site web
* HTML, CSS et JavaScript

---

## Chapitre 2 – Premiers pas avec HTML

* Structure d'un document HTML
* Les balises HTML
* Les titres (`h1` à `h6`)
* Les paragraphes
* Les retours à la ligne
* Le texte en gras et en italique

---

## Chapitre 3 – Les éléments principaux

* Les images
* Les liens
* La barre de navigation
* Les listes
* Les tableaux

---

## Chapitre 4 – Découverte du CSS

* Lier un fichier CSS
* Les sélecteurs
* Les couleurs
* Les polices
* Les tailles de texte
* L'alignement
* Les bordures
* Les marges
* Le padding
* Les classes
* Les identifiants (`id`)
